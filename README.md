# 集客AP的弱信号剔除功能

给集客 AP 设置两道信号门槛：手机要连接时，信号低于 **−75 dBm** 就拒绝这次接入；手机已经连上后，连续三次测到信号低于 **−82 dBm** 才断开。两个数值都可以调整，判断由手机所连的那台 AP 执行。

**已核对的固件**：AX1800MI、AX5RM 的 `7.1_2022032400`，以及 N3000 的 `7.2_2022111500`、`8.0_2024061700`。同型号的其他构建需要另行核对无线驱动。

## 我的 AP 能直接用吗？

- **只有原厂网页账号** → [看原厂 AP 实际是怎样装的](docs/getting-started.md)。公开仓库没有网页安装器，只有网页登录权限时，无法自行完成整套安装。
- **后台已有「弱信号接入与剔除」面板** → [在面板里启用、调门槛或关闭](docs/getting-started.md#panel)。
- **已有管理员命令行和文件传输权限** → [在一台 AP 上试用公开工具](docs/shell-lab.md)。可以先观察信号，无需改驱动或重启。

> **现场连接方式**　实装时先登录 AP 的 Web 后台，借助特定固件的参数校验缺陷取得临时系统权限，全程未用 SSH。仓库 ZIP 和单个 `.ko` 文件都不能作为固件升级包上传。

## 同一部手机，为什么有时能用、有时连不上？

假设沿用上面的门槛。表中的信号是 **AP 收到手机的信号**，数值越负，信号越弱。

| AP 测到的信号 | 此时发起连接 | 手机已经连着 |
| --- | --- | --- |
| −75 dBm | 通过信号检查 | 保持连接 |
| −78 dBm | 拒绝本次接入 | 保持连接 |
| −82 dBm | 拒绝本次接入 | 保持连接 |
| −83 dBm | 拒绝本次接入 | 连续三次低于门槛，复查仍低才断开 |

因此，手机走远到 **−78 dBm** 时还能用；在原地关开 Wi-Fi，再连同一台 AP 就会被拒绝。三次采样可以都是 −83 dBm，只要是三次新的无线活动。休眠设备留下的同一条读数不会反复计数。

想判断手机是被原 AP 断开，还是自己切到了另一台 AP，可按[验证指南](docs/verification.md)核对接入点、关联响应和剔除日志。
